# Υπερωρίες — εφαρμογή Android μέσω PWA

Ελληνική εφαρμογή για καταγραφή υπερωριών και υπολογισμό συμφωνημένων ποσών.

## Ενεργοποίηση δημοσίευσης
1. Άνοιξε Settings → Pages.
2. Στο Build and deployment, επίλεξε **Deploy from a branch**.
3. Επίλεξε branch **main** και φάκελο **/(root)**, μετά πάτησε **Save**.
4. Περίμενε να ολοκληρωθεί η δημοσίευση. Η διεύθυνση θα είναι https://arisxontzakis298-create.github.io/yperories/.
5. Άνοιξε τη διεύθυνση στο Chrome του Android και από το μενού ⋮ επίλεξε **Install app** ή **Add to Home screen**.

## Κανόνες υπολογισμού
- Δευτέρα–Παρασκευή: 10:30–12:29 = €15, 12:30–14:29 = €20, 14:30–16:30 = €30.
- Πάνω από 16:30 σε εργάσιμη ημέρα: απαιτείται προσαρμοσμένο ποσό.
- Σάββατο: 1,25 × μηνιαίος μισθός / 25. Κυριακή: 1,75 × μηνιαίος μισθός / 25.
- Το προσαρμοσμένο ποσό αντικαθιστά τον αυτόματο υπολογισμό.
- Διαθέτει κατάσταση πληρωμής, φίλτρο μήνα, εξαγωγή CSV και τοπική αποθήκευση.

**Απόρρητο:** Οι καταχωρίσεις αποθηκεύονται στον browser της συσκευής και δεν ανεβαίνουν στο GitHub. Μην ανεβάζεις προσωπικά στοιχεία στο repository.

Σημείωση: Οι υπολογισμοί ακολουθούν τους κανόνες που όρισε ο χρήστης και δεν αποτελούν επίσημο υπολογισμό μισθοδοσίας.
