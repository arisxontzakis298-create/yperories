# Οικογενειακά Οικονομικά

Ελληνική, εγκαταστάσιμη web εφαρμογή για κοινό οικογενειακό προϋπολογισμό σε Android και iPhone. Περιλαμβάνει ατομικούς λογαριασμούς, κοινό νοικοκυριό, συγχρονισμό cloud, έσοδα/έξοδα, προσαρμοσμένες και έτοιμες ετικέτες, μηνιαίους προϋπολογισμούς, επαναλαμβανόμενα πρότυπα, αναφορές και αντίγραφα JSON.

## Σημαντικό για την ασφάλεια

Η εφαρμογή **δεν είναι έτοιμη για πραγματικά οικονομικά δεδομένα** μέχρι να ρυθμιστεί το Supabase. Δεν καταχωρίζει οικονομικά στοιχεία σε τοπικό demo ως υποκατάστατο της ασφαλούς βάσης. Το frontend χρησιμοποιεί publishable/anon key και η πρόσβαση πρέπει να ελέγχεται από RLS.

## Ρύθμιση Supabase

1. Δημιούργησε project στο Supabase και κράτησε το Project URL και το publishable key (ή anon key).
2. Στο Supabase SQL Editor, εκτέλεσε ολόκληρο το αρχείο `supabase-schema.sql`.
3. Στο αρχείο `config.js`, αντικατάστησε τις τιμές `YOUR_SUPABASE_PROJECT_URL` και `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY`.
4. Στο Supabase Authentication, ρύθμισε το Site URL και τα Redirect URLs για το δημοσιευμένο GitHub Pages URL. Για ευκολότερη δοκιμή, κράτησε την επιβεβαίωση email ενεργή και επιβεβαίωσε τον λογαριασμό πριν τη σύνδεση.
5. Δημοσίευσε το repository μέσω GitHub Pages (branch `main`, folder `/(root)`). Η εφαρμογή θα είναι στη διεύθυνση `https://arisxontzakis298-create.github.io/yperories/oikonomika/`.
6. Άνοιξε το URL στο Chrome σε Android ή Safari σε iPhone και επίλεξε «Προσθήκη στην αρχική οθόνη».

## Λογαριασμοί και κοινή χρήση

- Κάθε μέλος δημιουργεί δικό του λογαριασμό.
- Το πρώτο μέλος δημιουργεί νοικοκυριό και μοιράζεται τον κωδικό πρόσκλησης μόνο με τα άτομα που εμπιστεύεται.
- Τα υπόλοιπα μέλη συνδέονται με δικό τους λογαριασμό και εισάγουν τον κωδικό.
- Τα δεδομένα προστατεύονται από πολιτικές Row Level Security (RLS) στη βάση, όχι μόνο από το frontend.

## Τι περιλαμβάνει

- Καταχώριση εσόδων/εξόδων σε ευρώ με ημερομηνία, περιγραφή, σημειώσεις και μία ετικέτα (έτοιμη ή προσαρμοσμένη).
- Έτοιμες ελληνικές ετικέτες για βασικές κατηγορίες.
- Σύνολα μήνα, υπόλοιπο, αναφορά εξόδων ανά ετικέτα.
- Όρια δαπανών ανά μήνα/ετικέτα.
- Επαναλαμβανόμενα στοιχεία ως πρότυπα. Δεν δημιουργούν αυτόματα συναλλαγές χωρίς επιβεβαίωση.
- Εξαγωγή και επαναφορά αντιγράφου JSON. Φύλαξε τα αντίγραφα σε ασφαλές σημείο· περιέχουν οικονομικά δεδομένα.
- Ενημέρωση δεδομένων με κουμπί ανανέωσης και όταν η εφαρμογή επιστρέφει στο προσκήνιο.

## Περιορισμοί

- Η εφαρμογή είναι PWA, όχι ακόμη native εφαρμογή από App Store/Google Play.
- Η πρόσβαση απαιτεί σύνδεση στο διαδίκτυο. Το shell μπορεί να αποθηκευτεί για εγκατάσταση, αλλά δεν γίνεται offline συγχρονισμός συναλλαγών.
- Πριν χρησιμοποιηθεί με πραγματικά δεδομένα, έλεγξε RLS, ρυθμίσεις email/redirect και διαδικασία ανάκτησης λογαριασμού στο δικό σου Supabase project.
